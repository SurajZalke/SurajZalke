### Step 3: Push Your Files
```bash

git init

# Add all files
git add .

# Commit
git commit -m "🎨 Add professional animated GitHub profile"

# Add remote (replace with your repo URL)
git remote add origin https://github.com/SurajZalke/SurajZalke.git

# Push to GitHub
git branch -M main
git push -u origin main
```

### Step 4: Enable GitHub Actions
1. Go to your repository: https://github.com/SurajZalke/SurajZalke
2. Click on **"Actions"** tab
3. If prompted, click **"I understand my workflows, go ahead and enable them"**
4. The snake animation workflow will run automatically

### Step 5: Manually Trigger Snake Animation (Optional)
1. Go to: https://github.com/SurajZalke/SurajZalke/actions
2. Click on **"Generate Snake Animation"** workflow
3. Click **"Run workflow"** button
4. Select **"main"** branch
5. Click **"Run workflow"**

Wait 1-2 minutes for the workflow to complete.

## 🐛 Troubleshooting

### Certificate Images Not Loading
- Ensure images are uploaded to `assets/certificates/` folder
- Check image file names match exactly
- Verify repository is public
- Wait a few minutes for GitHub CDN to cache

### Snake Animation Not Showing
- Check if Actions workflow completed successfully
- Ensure `output` branch was created
- Verify GITHUB_TOKEN has proper permissions
- Repository must be public

### Stats Not Loading
- Check username is correct: `SurajZalke`
- Ensure you have public repositories
- Verify profile is public
- Try refreshing after a few minutes
